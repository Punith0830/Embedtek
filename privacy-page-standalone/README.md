# Embedtek privacy policy — standalone review build

Status: Repository review draft

Integration: Not linked to the existing five-page website

Indexing: Disabled with `noindex, nofollow`

Open `privacy.html` to review the responsive policy-page direction.

## Content basis

The page is based on the user-supplied privacy-policy text dated 19 February 2026. The design preserves the policy’s major sections while making unverified operational and legal claims visible as review notes.

## Confirmation required before integration

- Legal company name and operating jurisdiction.
- Whether the mobile application, accounts, uploads, payments, location collection, analytics and advertising statements apply.
- Website/application hosting and international data-transfer locations.
- Security and supplier-audit claims.
- Data-rights process, response periods and retention rules.
- Final postal address and privacy-contact email.
- Terms of Use destination.

The file is deliberately isolated and includes `noindex, nofollow`. No existing HTML page has been modified to link to it.
